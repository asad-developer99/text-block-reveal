## Overview

A block-based text reveal animation, built with GSAP and Lenis smooth scroll.

This project is part of a collection of front-end animation and interaction studies exploring modern scroll effects, transitions, and micro-interactions.

## Built With

- GSAP
- Lenis
- HTML5 & CSS3

## Getting Started

No build step required — this is a static, single-file HTML project (markup, styles, and animation logic all live in one file) that loads its libraries from a CDN.

```bash
# Clone the repository
git clone https://github.com/asad-developer99/text-block-reveal.git
cd text-block-reveal
```

Then simply open `index.html` in your browser, or serve it locally for the best experience (recommended, since some browsers restrict local file access):

```bash
# using the VS Code "Live Server" extension, or:
npx serve .
```
